# Ingeniería de Datos I | Trabajo Práctico Obligatorio

### Universidad Argentina de la Empresa (UADE)

Proyecto académico desarrollado en el marco de la materia **Ingeniería de Datos I**, orientado al diseño, modelado e implementación de una base de datos relacional utilizando Microsoft SQL Server.

El trabajo tiene como objetivo aplicar los conocimientos adquiridos durante la cursada, abarcando desde el diseño de estructuras de datos hasta su implementación y manipulación mediante SQL.

---

## Objetivos del proyecto

- Diseñar un modelo de datos relacional a partir de los requerimientos del sistema.
- Definir entidades, atributos, relaciones y restricciones de integridad.
- Aplicar técnicas de normalización para reducir redundancias y evitar anomalías.
- Implementar las estructuras de la base de datos mediante SQL.
- Desarrollar consultas y operaciones para la gestión de la información.

## Tecnologías utilizadas

- **Microsoft SQL Server:** sistema de gestión de bases de datos relacionales.
- **SQL / T-SQL:** definición, consulta y manipulación de datos.
- **SQL Server Management Studio (SSMS):** entorno de desarrollo y administración de la base de datos.
- **Git y GitHub:** control de versiones y colaboración.
